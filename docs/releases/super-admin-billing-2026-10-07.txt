Implemented

Verified email is required by the database. Repeated submits cannot create duplicate portals. Reserved platform identities cannot self-provision as clients. Email domain is a display setting and never grants access to existing company records.

Only a verified global owner can draft bills or activate subscriptions. Service-only database functions and tables deny browser access. Audit records preserve subscription and user changes.
