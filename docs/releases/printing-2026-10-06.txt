USING THE OWNER REPORT
Accounting -> Owner statements (or Reporting -> Open statements).
Choose the accounting month using the workspace month selector.
Find and select an owner. All of that owner's current statement units are initially selected.
Clear selection or uncheck units to print a subset. Review the selected-unit count and totals.
Use Print selected units for the itemized report, or Download combined PDF for a single PDF.
Enable Include supporting receipts in PDF when original receipts are required.
Use Save file or Open PDF / print in the Report ready dialog if the automatic download does not start.
For one unit, use Print statement, Statement only PDF, Statement + receipts PDF, or Statement & receipts ZIP.
Save edited drafts before generating a report.
