OG OPERVIX GROUP · CORPORATE CLIENT CAMPUS
Devonshire work-computer setup kit

Purpose
Prepare the Devonshire computer to participate in the existing headquarters workflow: Leasing and HOA remain separate desks. DigitalOcean remains the single scheduler/coordinator. A verified workstation adapter would draft with the existing OpenAI session and obtain a separate Claude assessment, then save a proposed lesson to the exact client folder with an immutable intent and readback audit.

What this release implements
- A Windows startup script: synthetic regression tests and local tool preflight.
- A candidate, adapter-driven review pipeline with exact task/client/epoch/lease binding, fresh controls before each step, source isolation, separate draft/review steps, durable save intent and readback acceptance.
- Hold on provider authorization gaps, stale/paused controls, wrong desk/source, duplicate intents, failed model review or uncertain storage.
- Read-only DigitalOcean verification and detailed implementation/release instructions.

What is not connected by this package
The authenticated transport between DigitalOcean and the Devonshire computer, the target computer's ChatGPT/Claude sessions, and its source/storage adapters. The candidate module is not wired into the existing cloud runtime or app endpoint. It is deliberately not a new scheduler or an activation installer. These remaining connections must be implemented and live-tested on the target computer using NEXT-ACTION.txt. Passing synthetic tests or publishing this package does not establish full autonomy.

Run on the Devonshire computer
Open this folder in PowerShell, then:
  & .\Start-Devonshire.ps1

No administrator mode, execution-policy bypass, API key, package purchase, model invocation, credential display or access grant is performed. If PowerShell policy blocks the script, have the existing authorized IT process review/sign it; do not bypass policy. Node.js 22 must already be available. A signed-in ChatGPT/Claude desktop app does not prove the corresponding CLI or connectors are available.

Then open NEXT-ACTION.txt in the ChatGPT/Codex chat on that computer. It contains the implementation handoff, exact existing deployment locations, known holds and acceptance criteria. It is task guidance, not a grant of broader access or permission to bypass product approvals.

Keep private registry, real source excerpts, credentials and receipts in an approved private location outside Git. Example registration remains disabled. Do not copy OG_PRIVATE_WORKER_SECRET to the workstation or commit it.
